# 🍽️ Restaurant Intelligence System

## Overview
This project is an end-to-end Machine Learning pipeline developed as part of an internship to solve real-world restaurant analytics problems.

It focuses on:
- Predicting restaurant ratings (Regression)
- Classifying cuisines (Classification)
- Recommending restaurants (Recommendation System)

---

##  Key Features

### ⭐ Rating Prediction
Built a regression model to estimate restaurant ratings based on features like cost, votes, and other attributes.

### 🍜 Cuisine Classification
Developed a classification model to categorize restaurants into cuisines using machine learning techniques.

### 🔍 Recommendation System
Implemented a content-based recommendation engine using cosine similarity to suggest similar restaurants.

---

##  Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- Streamlit (for UI)
- Joblib (model persistence)
